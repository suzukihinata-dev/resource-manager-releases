# Resource Manager

時間の使い方を管理する macOS アプリです (ユーザーインタビュー用の配布版)。
Google カレンダーの予定を読み込んで分類し、長期目標・マイルストーンと、時間の配分・ブロック・ルーティーンをまとめて扱います。

## 必要なもの

- macOS 14 (Sonoma) 以上 (Apple シリコン・Intel のどちらでも動きます)

## 入れ方

1. [ResourceManager.zip](https://github.com/suzukihinata-dev/resource-manager-releases/releases/latest/download/ResourceManager.zip) をダウンロードして開く
2. 出てきた **ResourceManager.app を「アプリケーション」フォルダに移す** (移さないとアップデートが入りません)
3. 初めて開くときだけ、次のどちらかをします (Apple の公証を受けていないため、そのままでは開けません)
   - アプリを **右クリック (control + クリック) →「開く」→「開く」**
   - 「開けません」と出たら、**システム設定 → プライバシーとセキュリティ** の下の方にある **「このまま開く」** を押す

## アップデート

アプリが自動で新しい版を確かめ、見つかると「インストールして再起動」を聞く画面が出ます。
すぐ確かめるときは、メニューの **Resource Manager →「アップデートを確認…」** (または 設定 →「アップデート」) を押してください。
アップデートは開発者の鍵で署名されていて、アプリはその署名を確かめてから入れ替えます。

## データの扱い

- 入力した目標・予定の分類などは、**この Mac の中だけ** (`~/Library/Application Support/ResourceManager/`) に保存されます。開発者には送られません
- Google カレンダーは、アプリ内のブラウザで **ご自身のアカウント** にログインして読み書きします。ログイン情報もこの Mac の中だけに保存されます
- アプリが通信するのは、Google (カレンダー・Classroom) と、アップデートの確認先 (この GitHub のリリース) だけです
- アンインストールは、アプリと上のフォルダをゴミ箱に入れれば完了です
